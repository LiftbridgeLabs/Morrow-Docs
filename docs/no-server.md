# Don't have a server yet?

Morrow plays audiobooks from a server you run yourself: free software on a computer, a NAS, or a Raspberry Pi. The server stores your audiobooks, remembers where you are in each one, and streams them to Morrow on every device.

There is no Morrow account and no Morrow cloud, so your library stays on hardware you control. Morrow does not host, sell, or supply audiobook content.

## Choose a server

Morrow works with three free, self-hosted servers. They are listed in alphabetical order; any of them is a good home for an audiobook library.

- **Audiobookshelf**: a free, open-source audiobook and podcast server. [audiobookshelf.org](https://www.audiobookshelf.org/docs)
- **BookOrbit**: a self-hosted home for ebooks, audiobooks, comics, and PDFs. [bookorbit.app](https://bookorbit.app/installation)
- **Grimmory**: a self-hosted library for ebooks, comics, and audiobooks. [grimmory.org](https://grimmory.org/docs)

Each link goes to that project's own installation guide.

## Getting started

1. **Install the server.** Follow the setup guide on its website. It runs at home or on a host you rent.
2. **Add your audiobooks.** Point the server at the folder your audiobook files are in.
3. **Come back to Morrow.** Add the server in Morrow with its address and your account. The setup page for your server walks through it:
   [Audiobookshelf](audiobookshelf-setup.md), [BookOrbit](bookorbit-setup.md), or [Grimmory](grimmory-setup.md).

If you want to reach the server away from home, set up a reverse proxy or VPN as the server's own guide describes, and use that address in Morrow.

## Already have audiobook files?

Morrow plays audiobook files from your device with no server at all. On iPhone and iPad, choose **Add Audiobook Files** on the Home tab, then **Import Files** or **Link a Folder**. On Android, add **On This Device** in Settings, then import or link files or a whole folder from your phone, an SD card, or a storage app.

You can add a server any time later.
